## 🌱 Overview

In a fast-paced world, making time for personal well-being can be difficult. **SUKOON** aims to create a digital experience that encourages users to prioritize themselves and explore tools and resources that support their well-being.

The project focuses on building an approachable web experience with room to grow into a more comprehensive wellness platform.

## 🎯 Objectives

- Make wellness resources more approachable and accessible.
- Create a user-friendly digital experience.
- Encourage users to prioritize their personal well-being.
- Build a foundation for future wellness-oriented features and improvements.

## ✨ Features

- **Web-based experience:** Access the platform through a browser.
- **Dedicated home page:** A central starting point for exploring SUKOON.
- **Accessible interface:** Designed to make navigating the platform straightforward.
- **Live deployment:** Explore the hosted application without setting up the project locally.
